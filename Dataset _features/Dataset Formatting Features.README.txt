# Dataset Formatting Features – LM-Arena Project

This folder contains the feature extractor that reads **formatting-related features already provided inside the LM-Arena dataset**, specifically within the `conv_metadata` column.

These features serve two purposes:
1. **They represent the ground-truth formatting metrics provided by the LM-Arena evaluation system.**
2. **They allow comparison** between:
   - Dataset-provided features  
   - Our own module-generated formatting features  
   to validate correctness and consistency.

---

##  Extracted Features

### 1. **Bold Count**
- `dataset_a_bold`
- `dataset_b_bold`
Counts occurrences of `**bold**` or `__bold__` recorded by the dataset.

---

### 2. **List Counts**
Ordered (`1.`) and unordered (`-`, `*`) lists:

- `dataset_a_list_ordered`
- `dataset_a_list_unordered`
- `dataset_b_list_ordered`
- `dataset_b_list_unordered`

---

### 3. **Header Counts (Markdown)**
Dataset-recognized markdown headers:

- `dataset_a_header_h1` … `h6`
- `dataset_b_header_h1` … `h6`

---

### 4. **Token Counts**
Provided by LM-Arena scoring system:

- `dataset_a_tokens`
- `dataset_b_tokens`

---

### 5. **Context Token Counts**
Dataset metadata for user→assistant token windows:

- `dataset_a_context_tokens`
- `dataset_b_context_tokens`

---
